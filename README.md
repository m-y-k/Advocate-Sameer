## 🚀 How to Run & Preview

1. **One-click Image Setup**:
   - Double-click `setup_images.bat` in the project root folder.
   - It automatically copies the uploaded photos of Advocate Sameer Khan and the chamber into `assets/images/`.

2. **Open Website**:
   - Double-click `index.html` to open it directly in Google Chrome, Microsoft Edge, or any browser.
